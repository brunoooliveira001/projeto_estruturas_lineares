## Desafio 1: Sistema de votação de representantes

**Qual problema o programa resolve:**  
O programa simula uma votação entre três candidatos (Ana, Bruno e Carlos). Ele registra os votos, conta quantos cada candidato recebeu e informa o vencedor ou se houve empate.

**Quais estruturas foram utilizadas:**  
- Lista  
- Estruturas condicionais (if/else)  
- Método count()

**Como executar o programa:**  
No terminal, execute:Python 
desafio_01_votacao.py

**Exemplo de entrada e saída:**

Entrada:

Ana
Bruno
Ana
fim

Saída:

Resultado da votação:
Ana: 2 votos
Bruno: 1 voto
Carlos: 0 votos
Vencedor: Ana

## Desafio 2: Editor de texto com desfazer (Pilha)

**Qual problema o programa resolve:**  
O programa simula um editor de texto simples onde o usuário pode digitar palavras e desfazer a última palavra digitada.

**Quais estruturas foram utilizadas:**

No terminal, execute:Python 
desafio_02_editor_pilha.py

Entrada:

1
casa

azul

3

## Desafio 3: Fila de atendimento

**Qual problema o programa resolve:**  
O programa simula uma fila de atendimento, onde os alunos são atendidos na ordem em que chegam.

**Quais estruturas foram utilizadas:**  
- Lista (usada como fila)  
- Método append()  
- Método pop(0)  
- Conceito FIFO (First In, First Out)

**Como executar o programa:**  
No terminal, execute:Python 
desafio_03_fila_atendimento.py

**Exemplo de entrada e saída:**

Entrada:

1
João
1
Maria
2
3


Saída:

Chamando: João
Fila atual: Maria
